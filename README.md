# 👺 Demon Slayer: Kimetsu no Yaiba

Projeto desenvolvido com inspiração no universo de **Demon Slayer: Kimetsu no Yaiba**, com o objetivo de criar uma página temática dedicada ao anime e apresentar informações sobre sua história, personagens e principais aberturas.

## 📌 Sobre o Projeto

O projeto apresenta uma interface temática baseada no universo de *Demon Slayer*, reunindo diferentes informações da obra em uma única página.

A seção **Sobre** apresenta uma introdução à história de Tanjiro Kamado, sua jornada como caçador de demônios e os principais acontecimentos relacionados ao universo criado por Koyoharu Gotouge.

A seção **Personagens** reúne diversos personagens importantes da história, incluindo protagonistas, Hashiras e demônios, utilizando elementos visuais para tornar a experiência mais atrativa.

Também foi criada uma seção dedicada às **aberturas do anime**, apresentando músicas relacionadas às diferentes temporadas e fases da obra.

## 🧩 Estrutura do Projeto

- 🏠 **Início** — Página inicial do projeto.
- 📖 **Sobre** — Informações sobre a história de Demon Slayer.
- 👥 **Personagens** — Galeria com diversos personagens da obra.
- 🎵 **Aberturas** — Seção dedicada às músicas de abertura do anime.


## 🎵 Aberturas

A página também reúne as principais aberturas apresentadas ao longo do anime:

- 🎶 **1ª Temporada:** Gurenge — LiSA
- 🎶 **2ª Temporada:** Akeboshi — LiSA
- 🎶 **3ª Temporada:** Zankyou Sanka — Aimer

## 🎨 Design

A proposta visual foi construída para combinar com a temática de *Demon Slayer*, utilizando imagens dos personagens e uma organização voltada para proporcionar uma experiência visual mais imersiva.

A divisão do conteúdo em diferentes seções facilita a navegação e permite que o visitante encontre rapidamente as informações desejadas.

## 📱 Responsividade

O projeto foi desenvolvido pensando em diferentes tamanhos de tela, buscando proporcionar uma boa experiência de navegação tanto em **computadores quanto em dispositivos móveis**.

## 🎯 Objetivo

O principal objetivo deste projeto foi colocar em prática conhecimentos de desenvolvimento Front-End através da criação de uma página temática, trabalhando conceitos de:

- Estruturação de páginas;
- Organização de conteúdo;
- Estilização com CSS;
- Galeria de imagens;
- Navegação entre seções;
- Interatividade;
- Responsividade;
- Construção de interfaces temáticas.
